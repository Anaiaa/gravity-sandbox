# Gravity Sandbox

A 2D physics sandbox I'm building in Python with pygame. I'm learning physics and programming together by adding one piece at a time: gravity, collisions, orbits, and eventually sound and chaotic pendulums.

## Features
- [x] Falling ball with gravity and bouncing
- [ ] Vectors, air drag, floor friction, wall collisions
- [ ] Two balls colliding
- [ ] Click to spawn, drag to throw
- [ ] Live controls for gravity and bounciness
- [ ] Gravitational attraction and orbits
- [ ] Turning motion into sound
- [ ] Double pendulum and chaos

## How to run
1. Install Python 3
2. `pip install -r requirements.txt`
3. `python sandbox.py`

Click anywhere to drop the ball.

## What I'm learning
Forces, acceleration, vectors, energy conservation.
